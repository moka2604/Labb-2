# Skillnaden mellan git add och git commit
### Git add använder man när man vill lägga till alla ändrade filer på en gång medan git commit använder man för att beskriva ändringen man har gjort på sidan.

# Varför använder man branches
### Man använder branches för att kunna testa en idé utan att påverka koden i main och sen om det blir bra kan man mergea samman dom.

# Vad händer när man gör en merge
### När du mergar så överför du ändringar från en branch till en annan vilket kallas för pull request.

# Skillnaden mellan att pusha till Github och publicera direkt i Netlify
### Om man pushar till Github så skickar man ändringar i koden medan att publicera direkt i Netlify visar hela webbplatsen.

# Hur du exkluderar en specifik fil
### Antingen så kan du använda dig av gitignore eller så kan du skriva git add filnamn.html med alla filer förutom den.
